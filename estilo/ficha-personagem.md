# Ficha do Personagem (modelo para preencher)

> Preencha uma vez e cole no começo de toda conversa (ou deixe salvo nas instruções do Projeto do Claude).
> A **descrição visual fixa** deve ser copiada **igual, palavra por palavra,** em todo prompt do Seedance, pra o personagem não mudar de cara entre as cenas.
> No Seedance, use também uma **imagem de referência** do personagem e do ajudante.

---

## PROTAGONISTA

- **Nome:**
- **Espécie / tipo:** (precisa ser grande, forte e expressivo; ex.: gorila, urso, capivara gigante, tamanduá...)
- **Personalidade em 3 palavras:** (a base é sempre BRINCALHÃO e RISONHO; ex.: brincalhão, desastrado, coração mole)
- **Jeito de rir:** (ex.: gargalhada grave com a cabeça pra trás; risadinha pelo nariz)
- **Sotaque / jeito de falar:** (ex.: caipira mineiro, nordestino, gaúcho, carioca de morro...)
- **Bordões (3 a 5):** (precisa ser PRÓPRIO, não copie o do personagem de referência)
- **Como chama o ajudante quando dá bronca:**
- **Mania ou traço marcante:** (ex.: sempre experimenta a comida antes da hora; tem medo de altura)
- **Nicho principal:** (receitas / aventuras / obras / misto)

**Descrição visual fixa (em inglês, para o Seedance):**
```
(ex.: a large adult male orangutan with long reddish-orange shaggy fur, wide cheek pads, dark expressive eyes, heavy build, no clothing)
```

**Voz (em inglês, para o Seedance):**
```
(ex.: deep, raspy, slow male voice, Brazilian Portuguese with a strong rural caipira accent)
```

- **Nome / apelidos:**
- **Espécie:** (pequeno, fofo, com cor ou traço marcante)
- **Comportamento típico:** (rouba comida, se mete em perigo, sobe no protagonista...)

**Descrição visual fixa (em inglês):**
```
(ex.: a tiny white baby monkey with pink face and big round dark eyes)
```
