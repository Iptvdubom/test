# Fábrica de Roteiros — vídeos com IA (Claude + Seedance)

Sistema pra transformar uma **ideia** em **roteiro + prompts do Seedance** no mesmo estilo dos vídeos de referência, usando o seu próprio personagem.

## Passo a passo

1. Preencha a **ficha do personagem**.
2. Crie um **Projeto** no claude.ai e cole o **prompt-mestre** com a ficha nas instruções.
3. Mande uma ideia → confira o roteiro (Etapa 1) → aprove → receba os prompts cena por cena (Etapa 2).
4. Gere cada cena no Seedance com a imagem de referência do personagem e junte tudo num editor (CapCut, por exemplo).
